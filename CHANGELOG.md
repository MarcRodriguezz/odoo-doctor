# Changelog

## 0.1.0

First release.

- Audits Odoo 17 to 20 running natively, in Docker, over SSH, on Odoo.sh, or through the API.
- 111 checks across external exposure, configuration, users, operations, PostgreSQL, custom code, upgrade readiness, logs and disk.
- Terminal, HTML, JSON and SARIF reports.
- Binaries for Linux, macOS and Windows, on x86-64 and ARM64.

Not yet tested on real Odoo.sh or Odoo Online. See [what the tests prove](https://github.com/MarcRodriguezz/odoo-doctor/blob/main/docs/testing.md).
